🛒 Pick n Cheaper Supermarket — README
A responsive, single-file website and digital launch campaign dashboard for Pick n Cheaper Supermarket, built with semantic HTML5, CSS3, and vanilla JavaScript.

📌 Overview
Pick n Cheaper Supermarket provides affordable, high-quality groceries and essential pay-point services for South African households. This project contains a complete, production-ready website with 4 connected section views, interactive shopping tools, and an integrated digital marketing strategy panel.

✨ Key Features
Multi-Page Layout: Single-page navigation covering Home, About Us, Products & Services, Contact & Lead Generation, and the Digital Launch Campaign Panel.

Responsive & Accessible: Mobile-friendly layout using Flexbox/Grid, accessible navigation, and semantic HTML structure.

On-Page SEO: Built-in Open Graph, Twitter cards, and structured meta tags.

Form Validation: Real-time interactive contact form with POPIA compliance consent check.

⚡ JavaScript Interactivity
Promotional Modal Popup: Automatic welcome popup with a live 10-minute countdown timer for claiming a R50 coupon.

Dynamic Category Filter: Instant filtering across Fresh Foods, Cheaper Value Staples, and Pay Point Services.

Digital Shopping List: Interactive budget tool to add, check off, price-track, and calculate total estimated basket costs.

Mini Savings Calculator: Live range sliders calculating estimated monthly and annual grocery savings.

🚀 Digital Launch Campaign Strategy
Includes a built-in marketing panel detailing a 4-week launch plan:

Meta Ads: Geo-targeted local household awareness.

Google Local SEO: Capturing nearby store searches and map visits.

WhatsApp Broadcasts: Weekly digital deal pamphlets.

Community Outreach: Local flyers and opening-week promotions.
